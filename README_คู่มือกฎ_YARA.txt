   🛡️ CYBERGUARD AI - คู่มือการใช้งานและเพิ่มกฎ YARA RULES ด้วยตนเอง
========================================================================

โฟลเดอร์นี้ใช้สำหรับเก็บฐานข้อมูลกฎ YARA Rules (ลายนิ้วมือ/DNA มัลแวร์)
ระบบของ CyberGuard AI จะใช้ตรวจจับมัลแวร์สายพันธุ์ต่างๆ โดยอัตโนมัติ

ไฟล์กฎพื้นฐานที่ระบบมีให้:
1. ransomware.yar  -> ตรวจจับพฤติกรรมมัลแวร์เรียกค่าไถ่ (Ransomware)
2. infostealer.yar -> ตรวจจับโทรจันขโมยรหัสผ่าน/คุกกี้/Discord Token (InfoStealer)
3. hacktools.yar   -> ตรวจจับเครื่องมือเจาะระบบ (Mimikatz, Reverse Shell, AMSI Bypass)
4. index.yar       -> ไฟล์แม่บทที่รวมกฎทั้งหมดเข้าด้วยกัน

------------------------------------------------------------------------
📌 วิธีการเพิ่มกฎ YARA ใหม่ด้วยตัวคุณเอง:
------------------------------------------------------------------------
1. สร้างไฟล์ใหม่โดยใช้นามสกุล .yar เช่น "my_custom_rule.yar"
2. เขียนกฎตามมาตรฐาน YARA เช่น:

   rule Detect_Suspicious_Keyword {
       meta:
           description = "ตรวจจับคีย์เวิร์ดอันตรายเฉพาะ"
           severity = "DANGER"
       strings:
           $bad_word = "malicious_payload_domain.com" nocase
       condition:
           $bad_word
   }

3. เปิดไฟล์ "index.yar" และเพิ่มบรรทัด include ไฟล์ของคุณ:
   include "my_custom_rule.yar"

4. บันทึกไฟล์ - โปรแกรม CyberGuard AI จะนำกฎใหม่ของคุณไปใช้สแกนทันที!
